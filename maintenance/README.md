# Maintenance & Backups

This directory contains historical backups, migration tools, database setup utilities, and diagnostic test scripts.

## Structure
- `backup/` - Archived and deprecated scripts from earlier iterations. Not used in production.
- `db/` - Database initialization and schema creation scripts.
- `audit/` - System and database structure audit scripts.
- `tests/` - Local diagnostic tests (e.g. testing email, DB connections, notifications).
- `tools/` - Utility scripts for data migrations and asset updates.
